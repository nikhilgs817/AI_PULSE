# AIPULSE 0.2.2 Preview

- Expanded Overview with CPU/GPU, temperatures, RAM/GPU capacity, model/session activity, daily on-prem/tool token splits, app CPU/RAM, storage, backup/collector health and drill-down controls.
- Shared 15-minute, 1-hour, 6-hour and 24-hour Overview trend ranges, paired utilization/temperature plots and memory history.
- Wi-Fi adapter selection, actual upload/download Mbps, reported link speed and separate traffic histories. Filter-driver aliases are excluded; reset counters warm up rather than showing incorrect rates.
- All charts display dated time ticks, units and a visible timezone. Hover reveals observation time and UTC offset; missing history remains a gap.
- Documented central hub/Host Agent architecture with offline buffering, boot services, host selection and LAN/VPN/Internet profiles. Fleet service deployment is planned and is not shipped in this local-only UI release.
