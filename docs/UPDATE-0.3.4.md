# 0.3.4 token framework preview

Direct requests to an ordinary Ollama installation previously bypassed the optional AIPULSE gateway. Claude Code JSONL imports also did not cover cloud Cowork activity merely because Claude Desktop was open. Changing a time filter could not solve either collection gap.

This update adds optional persistent default-port Ollama capture, a durable metadata relay with replay/backfill after a fresh or restored dashboard, an embedded standard OTLP/HTTP receiver and explicit adapter coverage. It normalizes native Claude Code and Cowork events, keeps cache subsets out of additive totals, supports independent GenAI spans and vLLM counter intervals, and carries new accounting records through the authenticated fleet transport and baseline snapshots. Model/engine/instance identity, counter resets, first-sample baselines, duplicated batches and observation-period boundaries have explicit rules.

The native SQLite dependency is updated to 3.53.3 and storage now checks integrity at startup. Diagnostic reports survive individual query failures without persisting raw payloads. Suspect live-file copies are preserved for investigation; no salvage output is automatically substituted for a healthy store. Existing local working data, bounded compressed backup policy and default 90-day retention remain in place.

Local Windows checks on 8 November 2026 passed 74 data/framework checks, 72 desktop checks and 36 fleet checks. Separate process tests verified relay restart, commit-before-ACK, replay without duplication and backfill of a fresh dashboard after old events were acknowledged. A real, checksum-verified OpenTelemetry Collector Contrib 0.165.0 scraped a synthetic vLLM endpoint and exported protobuf to the actual app; both local and Kubernetes discovery profiles passed its configuration validator.

The installed Windows app was exercised against the existing Ollama server with three real embedding requests, including native API, OpenAI compatibility and the nested legacy gateway. Provider-reported input counts of 11, 12 and 14 appeared as exactly three completed observations, with no download or large-model inference. The default-port relay and original Ollama CLI listing were verified. These are controlled accounting checks, not a claim that every provider/model/version has been exercised.

Claude Desktop Code needs telemetry configuration in its execution environment. Official Cowork export requires eligible Team/Enterprise administration and a reachable collector; a personal cloud session may have no supported exact local token source. Unobserved historical calls cannot be recreated from hardware activity. The future user cluster and a real vLLM deployment have not yet been available for end-to-end validation. Codex's supported cumulative session import remains; native-only per-response formats and full ccusage-style sidechain reconciliation are outside this preview's coverage.

See [setup profiles](telemetry/README.md) and [the accounting architecture and pinned source review](TOKEN-COLLECTION.md). This is a source/local preview; the existing public release downloads are not silently replaced. Windows/Ubuntu CI results apply to the pushed revision and are reported separately.
